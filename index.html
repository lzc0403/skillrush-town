七大热点洞察

1

峰谷计价落地，开源定价权博弈进入新阶段

8/16 16:00 UTC 起 DeepSeek V4 Pro/Flash 正式执行峰谷计价：off-peak 仅为 peak 的一半（V4-Pro 高峰输出 $3.96/百万 tokens，空闲 $1.98）。结合智谱 Q1 提价 83%、腾讯混元部分接口涨超 460%，"开源=免费"叙事彻底失效。DeepSeek 用 Harness 把执行层开源对冲涨价流失风险——模型厂商从卖 API 转向卖工作流。

2

安全审查首成开源"闸口"：GLM-5.3 暂缓开放权重

智谱 Z.ai 8/14 发布 GLM-5.3（沿用 743B 基座、纯后训练 +50% 编程、Terminal-Bench 3.0 开源第一、CyberGym 超 Claude），却因网络安全审查暂缓开放权重——其 Project Glasswing 在真实项目发现 2436 个未修补漏洞（含 1097 中高危，跨度 26 年）。这是史上首次 AI 模型因安全影响评估延迟开源，标志 AI 安全审查从性能评估扩展到安全影响评估。

3

国产开源登顶全球：千问下载破 30 亿、占比 41% 首超美

阿里千问家族 6 个月累计下载破 30 亿次（HF 报告 20.45 亿），衍生超 30 万、稳居开源第一，超 Meta/谷歌。中国自研开源模型下载占比达 41% 首超美国。小红书 dots 实验室开源 280B（激活 16B）三模态 Agent 模型 dots3-note（512K 上下文），华为昇腾 Atlas 800/900 已完成 0-day 适配——国产硬件与模型进一步打通。

4

Agent 框架之争白热化：Harness 45h 破 10.5 万星

DeepSeek Harness（dsh）采用"一切皆插件"架构（模型/工具/技能/沙箱/循环全插件化），开源 45 小时 GitHub 星标达 10.5 万、Fork 超 1 万，正面切入 Codex / Claude Code 占据的编程执行层。同期 OpenAI 上线 GPT-5.6 多智能体 V2（网络请求降 98.2%、对话加载缩减 99.6%）；Anthropic 研究揭示多 Agent 会爆发"领地争夺"式互斗——协作协议与治理成新刚需。

5

工作马模型层集体重洗：Gemini 3.7 Flash 与 Grok 4.6

谷歌在 3.6 发布仅三周后推出 Gemini 3.7 Flash（FrontierCode 1.1 主榜 43.6% vs 3.6 的 34.4%，入门价 $0.75/$3.75、1M 上下文、可调思考）。SpaceXAI 发布 Grok 4.6（$2/$6，AA 智能指数 61 匹配 GPT-5.6 Sol，专为长程 Agent 调优，已在 Cursor/Grok Build 上线）。速度与上下文把竞争从跑分拉到延迟与长程成本。

6

端侧与国产地缘双突破：iPhone 跑 3970 亿参数

展示显示 3970 亿参数模型在 iPhone 本机离线生成文本，端侧推理里程碑，对云端 API 商业模式构成潜在威胁。Apple 联合阿里巴巴训练中国专属 LLM 获北京批准，将集成中国版 Apple Intelligence——这是北京首次为西方科技公司批准此类许可，AI 地缘格局出现松动信号。

7

自主 Agent 攻防进入实战：首例端到端 AI 黑客

以色列安全公司 Dream 记录疑似中国相关攻击者用公开 AI Agent 构建的系统，对台湾政府发动首例全自主端到端 AI 黑客：4 天内 8 个 Agent 协同映射 21 个政府系统、破解 85 账户、泄露 2500 条人事记录，遇阻自动切换战术。同期 ToolHazard 框架发布（环境模拟器 + 攻防 Agent 评估）。Agent 安全从理论风险转为 operational threat。
