1

国产开源编程模型登顶：GLM-5.3 + Qwen3.8 双线破局

8/19 智谱 GLM-5.3 API 上线，Artificial Analysis 智能指数 60 分，与 Claude Fable 5、GPT-5.6 Sol 同档、位列开源第一（纯后训练、Terminal-Bench 3.0 从 4.6→28.3），权重下周五 MIT 开源。同期阿里 Qwen3.8-27B 开源两天下载破 100 万登顶 HF（Apache 2.0、262K 上下文、4bit 仅 17G 显存本地跑）。国产开源从「追参数」进入「建生态」阶段。

2

「地板价」时代终结：峰谷计价 + 集体提价

DeepSeek V4-Pro 自 8/17 起执行峰谷分时计价（高峰输出涨 350%、缓存命中输入上调 11 倍），闲时半价。摩根士丹利测算中国大模型均价从 2025 Q1 的 12.2 元回升至 21.9 元（涨幅约 80%）：智谱累计提价 83%、腾讯部分接口涨 463%、DeepSeek 高峰输出 9 元/百万。「开源=免费」叙事失效，开发者被迫重规划调用时段与缓存策略。

3

智能体框架标准化：一切皆插件成为共识

DeepSeek Harness 开放测试，以「模型+框架」协同补齐 VibeCoding 入口（多智能体协同、沙盒隔离、任务编排）。Claude Platform 本周上线 Computer Use、Skills API 与 Files API 并新增浏览器操作工具；Mistral 推 Agentic Search（search/open/navigate/read/grep 五工具多步检索）；微软 Webwright 把点击转成可重复脚本。执行层与协作协议成确定性主线。

4

长程 Agent 专用模型与自主科研集群

小红书开源 dots3-notepreview 280B（Apache 2.0、512K 上下文，聚焦长程 Agent 多步推理/长周期规划）。闭源 RSI 实验更具信号：18 个 AI Agent 组成自主科研团队，月之暗面 Kimi K3 靠 Harness 编排在科研推理任务逼近 Anthropic Opus 5。多 Agent 集群智能验证「分工+互验+迭代」可模拟真实科研团队。

5

端侧 / 桌面 Agent 向终端本地纵深

LiquidAI 发布 LFM2.5-VL-3B（仅 3B 参数，手机端本地读屏+自主操作，无需云端传输）；字节豆包 Windows 版上线「工作任务」虚拟桌面，Agent 可在云端虚拟桌面直接操作 Windows 应用；Agent Island 桌面伴侣支持多编码工具状态监测。AI 交互从云端对话向终端本地执行下沉。

6

资本整合加速：AI 编程与 Agent 赛道巨头入场

SpaceX 以 600 亿美元全股票收购 Cursor 正式生效（AI 编程最大并购，核心团队并入 Grok）；市场消息称腾讯拟从 Meta 手中接盘 Manus 成最大股东；Stripe 达成收购 AI 模型聚合平台 OpenRouter 协议。Anthropic Q2 营收 115 亿美元（同比约 14 倍）、筹备 10 月 IPO 估值 2 万亿——To B 按 token 计费商业模式验证可持续现金流。

7

中国模型调用量连续 16 周居首

OpenRouter 数据 8/10-16 全球大模型总调用 75.3 万亿 Token（环比 +9.13%），其中中国 36.84 万亿、美国 10.26 万亿，中国连续 16 周领先（占比约 49%）。单模型榜 DeepSeek-V4-Flash 以 7.22 万亿登顶，腾讯 Hy3、DeepSeek-V4-Pro、智谱 GLM-5.2 进入前五——国产开源在开发者侧实际使用率形成稳定领先。
