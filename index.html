七大热点洞察

1

DeepSeek Harness：模型厂商抢下"执行层"入口

8/13 深夜 DeepSeek 以 MIT 协议开源首款智能体运行框架 DeepSeek Harness（DSH），采用"一切皆插件"架构——模型、工具、技能、会话、沙箱、调度全部由 Cordis 元框架的插件组合而成，可自由替换重组。仓库半小时破万星、两小时破 3 万星。这标志着 DeepSeek 从"模型提供商"转向"全链路 AI 工作流构建者"，正面切入 Codex / Claude Code 占据的编程执行层，从卖 API 转向卖结果。

2

中国开源阵营三天内"围剿"闭源

8/13–8/15 窗口内，DeepSeek V4 Pro 正式版、阿里 Qwen3.8-27B（Apache 2.0，262K 上下文可扩 1M）、智谱 GLM-5.3（7430 亿参数）、Meta Muse Glimmer 同期开源。据 Hugging Face 2026 春季报告，中国自研开源模型下载占比达 41%，首次超过美国、累计下载破 100 亿次。开源从行业边缘被推到中心，倒逼整个定价体系重建。

3

Agent 能力成开源模型新标尺

本轮开源更新把"能否干活"当作核心卖点：DeepSeek V4 Pro 在 DeepSWE 基准从预览版 12.8 跃升至 62.7；Qwen3.8-27B 原生支持 Agent，DeepSWE 从 13.3 升至 42.2、部分基准超 Opus 4.6 Max；GLM-5.3 编程较 5.2 提升 50%、登顶 Terminal Bench 3.0 开源第一，并"涌现"网安能力——累计发现 2436 个漏洞含 1097 个中高危。模型优劣不再只看跑分。

4

价格屠夫告别地板价，定价权博弈加剧

8/13 DeepSeek 公布峰谷定价：8/17 起 V4 Pro 高峰输出 27 元/百万 tokens（空闲 13.5 元），较此前 6 元整体上调数倍；智谱 Q1 提价 83%、腾讯混元部分接口涨超 460%、阿里百度相继提价。与此同时阿里正研究 Qwen3.8-Max 商用分成机制——"开源 ≠ 商用免费"成为头部厂商从"烧钱换份额"转向"算账过日子"的共识。

5

头部实验室的算力与治理布局

Anthropic 最快 10 月 IPO、估值或破 2 万亿美元，并洽谈约 60 亿美元收购视频初创 Decart 补强推理效率；Hassabis 卸任 DeepMind CEO 前推动"IAEA 式"独立 AI 安全机构；数据中心巨头 Vantage 评估千亿级 IPO。算力与治理正从技术议题升级为资本与地缘议题。

6

速度与上下文成 API 新分层维度

OpenAI 联手 Cerebras 推出 GPT-5.6 Sol Ultrafast 模式，输出达 750 tokens/秒、较 Opus 4.8 Fast 快约 5 倍；Grok 4.6 独立评测上下文 500K、同类任务仅约 53 回合（Opus 5 需 103 回合）；OpenAI Codex 活跃用户破 1500 万。前沿竞争从跑分榜单延伸到延迟体验与长程成本。

7

AI 终端化与"主动式 AI"落地

谷歌 Pixel 11 以 Tensor G6 + Gemini"主动式 AI"为核心卖点（跨应用感知并自动执行）；苹果中国定制模型、英伟达 AI PC 推进端侧；Anthropic 实验让 Claude 接管 App 维护——累计 388 个 PR、180 个已合并，工程师只剩"签字"环节。Agent 生态从云端下沉到终端与日常工程流。
